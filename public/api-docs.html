VAGÃO · Modelo e API

Uma rede ferroviária imaginária: tempo, espera e conexões mudam uma viagem.

O domínio

Seis estações, 112 serviços de um dia abstrato. Busca de caminhos simples com até cinco trechos e oito minutos mínimos de conexão. Ordenação por chegada ou trocas, desempate estável. Não são viagens reais.

Endpoints

OpenAPI JSON ↗ · Catálogo JSON ↗

Exemplo local

curl http://127.0.0.1:59100/api/catalog
curl http://127.0.0.1:59100/api/health

Use default_input do catálogo como corpo JSON de POST /api/compute. Criação devolve token uma vez; envie Authorization: Bearer demo_… para operações privadas. PUT exige title, input e expected_revision. Compartilhar exige expected_revision e published.

Erros e limites

JSON com code, message e request_id. 400 URL/JSON; 403 origem; 404 ausente/sem acesso; 409 revisão/selo; 413 tamanho; 415 mídia; 422 domínio; 423 bloqueio temporal; 429 cota; 500 indisponibilidade. Sete dias, doze criações/hora UTC, trinta revisões, JSON de 16 KiB.

Universo sintético, sem substituir serviços ou medições reais.
